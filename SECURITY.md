# Security

Report vulnerabilities privately: **Security › Report a vulnerability** on this repository, not in a public issue. You'll
get an answer within a week. Only the latest release gets fixes.

- The API key is stored in Seanime's extension settings and sent only to your Listick address. Use `https://`.
- The key can read lists and record plays only. Replace it in Listick (Settings › Connections › Seanime) if it leaks.
- Network access is requested for any address; the plugin calls only your Listick address.
